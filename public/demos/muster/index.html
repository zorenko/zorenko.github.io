    Questions

    Short answers.
    No sales call.

    What people ask before they point something at their ~/.claude or ~/.agents folder.

    Something we missed?

    What does Muster work with?

    Claude Code and Codex on macOS. It reads your global skills in ~/.claude/skills and ~/.agents/skills (plus Codex’s older ~/.codex/skills), the skill folders inside your projects, and skills that came with plugins, including ones you installed from skills.sh or GitHub. Other agents come later, then Windows and Linux.

    I use both Claude Code and Codex. Does that help?

    That’s where the mess grows fastest: you copy a skill over for Codex, then edit only one copy. Muster reads both, spots skills that exist in both places, shows where the copies drifted apart, and brings them back in line.

    Will it change or delete my skills?

    Not without asking. The scan only reads. Every fix is a suggestion: apply it, copy it and do it yourself, or skip it. Unused skills you wrote get archived, not deleted.

    Does anything leave my Mac?

    Nothing goes to us. There’s no Muster account and no Muster cloud. The daily check asks your own Claude Code or Codex to read your skills, so their contents go only where that agent already sends them.

    Do folders change anything for my agent?

    No. Folders and subfolders live in Muster, so you can sort a hundred skills however you like while every file stays exactly where Claude Code or Codex looks for it. Moving a skill between folders never touches the skill itself.

    Does it use my Claude or ChatGPT plan?

    Yes, if you sign in to Claude Code or Codex with your Claude or ChatGPT account: the check runs through the one you pick and counts toward that plan like any other session. With an API key, it’s billed to that key. By default it runs once a day and when you add or remove a skill; you can switch it to only when you ask.

    Will a cleanup make my agent cheaper to run?

    A little on every turn, and turns add up. Every skill’s description, about 100 tokens, goes with every turn, used or not, and a skill that loads by mistake keeps its full instructions in the session. With fewer skills, they all stay in view: past a limit, Claude Code drops descriptions, least-used first. On a Claude or ChatGPT plan, your limits last longer. On an API key, the bill is smaller, though most of these tokens are cached and cheap. Run /context in Claude Code before and after a cleanup to see it.

    How does it spot conflicts and duplicates?

    It reads every skill’s description, which is what your agent matches your request against, and then the full instructions. Two skills only count as a conflict if both would load for the same request and it can quote the lines that contradict; similar but compatible skills are duplicates. The fix depends on who owns the skill: yours get edited or merged, installed ones get a tiebreak line in ~/.claude/CLAUDE.md or ~/.codex/AGENTS.md, and unused ones get archived or switched off.

    How do I get it, and how do I remove it?

    The install comes with your invite. Uninstalling removes the app, its folder and its daily schedule; Muster stores nothing anywhere else. Your skills stay as they are, apart from fixes you applied.

    What if it doesn’t work for me?

    It’s free for personal use, so all it costs you is the uninstall. But please first and tell us what went wrong. That’s how it gets fixed for the next person.

    What about my team?

    That’s next. You’ll be able to suggest a skill from your Mac to a team space; an admin approves it, and Muster puts it on every teammate’s Mac. Connectors like Linear, GitHub and Notion come with it. Personal use stays free; team plans will be paid. If that’s what you need most, pick it when you sign up.
